# Runovel Automation

This repository will contain reusable GitHub Actions workflows and shared
automation for Runovel projects.

The initial repository intentionally contains no workflows. Reusable workflows
will be introduced through reviewed, versioned changes with least-privilege
permissions, pinned dependencies, and compatibility validation against current
projects.

## Planned scope

- validation and testing
- security and dependency checks
- release and artifact publishing
- container build, SBOM, provenance, and signing
- documentation validation and deployment

Report vulnerabilities through the organization-wide
[security policy](https://github.com/runovelhq/.github/security/policy).
